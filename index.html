What the integration does

The integration reads an authorized Nest thermostat’s temperature, humidity, operating mode and setpoints, and allows the household owner to change thermostat modes and setpoints through Home Assistant. Google Cloud Pub/Sub delivers device updates. Household automation may use these readings to coordinate a ceiling fan.

This is a personal integration, not a public smart-home service. This static website provides information only and offers no thermostat login or control. The Nest connection uses Google’s cloud services even when Home Assistant runs on the household network.

Privacy notice

Effective October 6, 2026.

Access is limited to devices the Google account owner authorizes. The Nest authorization can include home and room names, ZIP code, basic device details, temperature and humidity readings, HVAC state, settings and setpoints. The app also requests permission to view and manage Google Cloud Pub/Sub topics and subscriptions for device-event delivery.

These data are used for household monitoring, thermostat control and home automation. OAuth credentials and integration configuration are stored in the household’s private Home Assistant configuration. A separate private household control service may access Home Assistant using an authorized token. The public GitHub Pages site does not receive thermostat readings, credentials or home information.

The integration does not sell household data or use it for advertising. Google processes authorization, device commands and event delivery under its own policies. GitHub hosts this information site and may collect ordinary website access data under its privacy statement. Household services may retain device history, logs and backups according to their configured retention settings; no fixed automatic deletion period is promised here.

The owner can revoke app access in Google Account connections and remove the Nest integration from Home Assistant. Revocation stops future access; previously recorded household history and backups may remain until the owner deletes them.

For questions, contact the operator through this repository’s issue tracker. Issues are public: do not post credentials, thermostat records, addresses or other private household information.

Usage information

This integration is intended for the operator’s own household. It is provided without a service availability guarantee and depends on Home Assistant, Google Nest and network connectivity. The thermostat’s existing protections and physical controls remain essential. The owner is responsible for authorizing devices, choosing settings, maintaining the installation and reviewing automation behavior.

This personal project is not affiliated with or endorsed by Google, Nest, GitHub or the Home Assistant project. No public account registration or paid service is offered on this website.
